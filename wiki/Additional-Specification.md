# Дополнительная спецификация

Нефункциональные требования лабораторной работы № 3 (НФТ-1…НФТ-6)
дополнены ограничениями уровня API.

| ID | Категория | Требование |
| --- | --- | --- |
| НФТ-1 | Производительность | Отклик поиска и каталога ≤ 2 с при 1000 активных пользователей; карточка книги ≤ 1,5 с |
| НФТ-2 | Надёжность | Доступность не ниже 99,5 (процентов); неоплаченные заказы отменяются через 24 ч |
| НФТ-3 | Безопасность | Хэширование паролей, платежи только через шлюз (PCI DSS), разграничение прав, HTTPS |
| НФТ-4 | Удобство использования | Оформление заказа ≤ 4 шагов; покупка без регистрации ≤ 2 экранов; WCAG AA |
| НФТ-5 | Переносимость | Chrome/Firefox/Safari/Edge, Android 10+, iOS 15+, Docker |
| НФТ-6 | Сопровождаемость | Модульная структура по ограниченным контекстам, Gherkin-тесты |
| API-1 | Транспорт | Только HTTPS; JSON (`application/json; charset=utf-8`); версия в префиксе `/api/v1` |
| API-2 | Аутентификация | JWT (HS256), access-токен 60 мин, refresh-токен 7 суток, отзыв при logout |
| API-3 | Авторизация | Роли guest/customer/manager/admin; административные операции → 403 при отсутствии прав |
| API-4 | Коллекции | Пагинация `page`/`perPage` (по умолчанию 1/20), фильтры и `sort` в query |
| API-5 | Ошибки | Единая схема `Error` (`code`, `message`, `details[]`) и корректные HTTP-коды |
| API-6 | Интеграции | Webhook шлюза проверяется по HMAC-SHA256 и обрабатывается идемпотентно |
| API-7 | Ограничения | `429` при превышении частоты рассылки (ФТ-7); `409` при нарушении уникальности |
| API-8 | Идемпотентность | Повторный webhook с тем же `externalId` не создаёт второй платёж |

**Ограничения проекта:** Python 3.12 / Django 5 / Django REST Framework; СУБД PostgreSQL 16; проектное расписание — сентябрь–декабрь 2026 г.
